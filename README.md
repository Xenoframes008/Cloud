# Cloud

Starter repository for the Cloud project.

## YouTube-ready videos

Raw clips were not checked in. Use [`youtube/`](youtube/README.md) to encode footage to YouTube’s recommended 1080p and Shorts specs, or to rebuild the branded Cloud starter demo.

```bash
cd youtube
bash scripts/encode_youtube.sh path/to/clip.mp4 out/exports/clip_youtube_1080p.mp4 --landscape
```
